# Security

## Report a problem privately

Please **don't open a public issue or discussion, or send it by X DM,** for security problems. Use GitHub's private reporting instead:

**[Report a vulnerability](https://github.com/dax8it/nous-girl-stackchan/security/advisories/new)** (Security tab > Report a vulnerability).

Include what you found, which version (Settings > About) and how to reproduce it. Don't include real passwords, tokens or other people's data.

## What counts

- A secret, token, email address or private server address in this repo or in a release file.
- Firmware that connects somewhere the user did not set.
- A way for someone on the network or internet to control a robot or read its camera or microphone.
- Setup steps in the docs that leave a server open to the internet.

## What to expect

This is a hobby project with one maintainer. You'll get a reply when the maintainer can, usually within a week. Fixes go into a new release, and the advisory is published after the fix.

## Supported versions

Only the latest public release (currently `v3.6.7-dj7`, beta) gets fixes. Older checkpoints are kept for rollback only.
